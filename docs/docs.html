The plan, the lookbook and the spec for the IND Election Night broadcast app. The Studio is the site's front page; the ticker and graphics are fixed addresses it hands out.

Build planStories, burndown, the log of every change, and what is left. Graphics lookbookEvery chart by series, with its data source and on-air notes. Technical specRequirements, architecture as built, open questions. Watch Party designThe public site for every race in the AP feed (separate deployment).

Addresses

  • Studio — the producer's page: the live ticker, the live screens, featured races and every chart. Password required; it used to live at /studio, which now forwards here.
  • Ticker — the live crawl at 1920×1080; add ?bg=green for the key, or build one from its address (the Studio shows how).
  • Live Screen One and Live Screen Two — two fixed pages showing whatever chart was last published to them.
  • Graphics are one address each under /g/ (for example /g/B5?bg=black&race=NE-SEN), 1920×1080, transparent by default; the Studio has a Copy URL on every card.
  • Candidates and Photos — the curated independent index and the photo manifest, with live shares.
  • Code — cd studio, npm install, npm start runs the whole app on a laptop as a standby; the README covers passwords, failover and the night.
