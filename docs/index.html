ap-ind

AP Elections API middleware for election night. Demo build.
Docs site · no live data. The server that polls AP and serves the graphics and candidate index runs on the studio machine (or locally with npm run dev). This site holds the documents only.

Design

  • Graphics data options — candidate graphics by segment, with a data audit and on-air key notes
  • Technical spec — requirements, architecture, plan, open questions
  • Watch Party design — public site for tracking every independent race; separate deployment

Data server only

  • Candidate index — bios, verified photos and live numbers for the featured races

Graphics (1920×1080) server only

  • Ticker (transparent, green key or black)
  • Race result, one page per race by AP race id

API server only

  • /api/status · /api/snapshot · /api/races · /api/events · /api/ticker · /api/producer · /api/candidates · /healthz · WebSocket /ws

Code

  • github.com/eriktrautman/ap-ind — clone, put an AP key in .env, npm install, npm run dev
