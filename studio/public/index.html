Live results for the broadcast about independent candidates.

This site reads the AP Elections API once a minute and produces two things: dynamic, API-driven charts for every federal race and major ballot initiative, full-screen at 1920×1080, and a live broadcast ticker. Each is a fixed web address that updates itself as the count comes in.

The Studio is where producers decide what goes out: which races the ticker follows and the lines it crawls, the chart on each live screen, and the featured races and charts for the show. Every publish is signed with the producer's name and is live within five seconds.

Sign in to the Studio

A password is needed. Each person has their own, with producer, publisher or read-only rights; ask the producer for yours.
